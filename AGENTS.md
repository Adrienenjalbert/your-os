## What agents should optimize for

In priority order:

1. **Outcome over output.** Every change must move ROOS, indexation, AI-citation share, or pipeline conversion. Ranking on its own is not an outcome. See [.agents/rules/050-growth-lead-priorities.md](./.agents/rules/050-growth-lead-priorities.md).
2. **Funnel-aware by default.** Intent → CTA → micro-conversion → email warm-up → primary conversion. Skipping links breaks the loop. See [.agents/rules/070-funnel-discipline.md](./.agents/rules/070-funnel-discipline.md).
3. **Human-in-the-loop on the right decisions.** Five HITL gates: portfolio (quarterly), brief sign-off (per brief), YMYL (conditional), cannibalization merge (event-driven), monthly portfolio review. Everything else is autonomous. See [.agents/rules/060-human-in-the-loop.md](./.agents/rules/060-human-in-the-loop.md).
4. **Per-tenant blast radius.** No tenant can break another. Strapi outage cannot break its own site (last-known-good cache). See [.agents/rules/030-strapi-isolation.md](./.agents/rules/030-strapi-isolation.md).
5. **Reversible by design.** Codemods for breaking schema changes. Byte-equivalence for extractions. Draft-mode for content. See [.agents/rules/020-byte-equivalence.md](./.agents/rules/020-byte-equivalence.md) and [.agents/rules/040-versioning-codemods.md](./.agents/rules/040-versioning-codemods.md).
6. **2026 SEO/AEO/GEO unification.** Treat SEO, GEO, AEO, and LLMO as one operating system; tactical deltas are captured in [SEO_OPERATING_STANDARDS.md](./SEO_OPERATING_STANDARDS.md).

## Verification before declaring done

- `pnpm turbo run lint typecheck test build` passes.
- New packages have `package.json`, `tsconfig.json`, `tsup.config.ts`, `vitest.config.ts`, `src/index.ts`, `README.md`.
- A Changeset entry exists if a published package changed.
- Brand-lint, byte-equivalence (where applicable), and the Strapi isolation import-graph rule pass.
